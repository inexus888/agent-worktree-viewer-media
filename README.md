# Agent Worktree Viewer: listing media

Public images and animations used on the Visual Studio Marketplace page of
[Agent Worktree Viewer](https://marketplace.visualstudio.com/items?itemName=morten-lejboelle.agent-worktree-viewer).

This repository contains no extension source code. The Marketplace README links to these files by commit, so
existing listings keep working when new images are added.
